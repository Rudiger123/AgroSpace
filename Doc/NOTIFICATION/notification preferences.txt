# ✅ Pourquoi tu as eu l’erreur « Call to undefined method User::preferences() » ?

Dans ton listener, tu avais cette ligne (maintenant commentée) :

```php
// ->whereHas('preferences', function ($query) use ($event) {
```

Même si tu l’as commentée maintenant, **c’est clairement elle qui provoquait l’erreur**, car ton modèle `User` ne possède pas cette relation :

```php
public function preferences() { … }
```

Donc Laravel plante.

Maintenant que c’est commenté, l’erreur devrait disparaître.

# ✅ **OPTION 2 — Tu veux un système vrai de préférences utilisateur (recommandé)**

Tu veux que chaque utilisateur choisisse :

* Recevoir les nouvelles offres ?
* Recevoir les nouveaux articles ?
* Recevoir les nouveaux avis ?
* Etc.

Alors 👉 on crée une table preferences + relation.

### 🔹 Migration

```php
Schema::create('user_preferences', function (Blueprint $table) {
    $table->id();
    $table->foreignId('user_id')->constrained()->cascadeOnDelete();
    $table->boolean('notify_new_offers')->default(true);
    $table->boolean('notify_new_demands')->default(true);
    $table->boolean('notify_articles')->default(true);
    $table->timestamps();
});
```

### 🔹 User.php

```php
public function preferences()
{
    return $this->hasOne(UserPreference::class);
}
```

### 🔹 Listener

```php
$interestedConsumers = User::whereHas('preferences', function ($query) {
    $query->where('notify_new_offers', true);
})->get();
```
