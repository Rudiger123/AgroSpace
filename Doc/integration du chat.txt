## 🔌 Intégration Livewire

Pour intégrer avec Livewire, vous devrez :

1. **Créer le composant Livewire** :
```bash
php artisan make:livewire Chat/ChatManagement
```

2. **Remplacer les données statiques** par :
```blade
wire:model="searchQuery"
wire:click="selectConversation({{ $conversation->id }})"
@foreach($conversations as $conversation)
```

3. **Ajouter les événements temps réel** :
```blade
wire:poll.5s="loadNewMessages"
x-on:message-sent.window="scrollToBottom()"
```

4. **WebSocket pour le temps réel** (Laravel Echo + Pusher/Reverb)
