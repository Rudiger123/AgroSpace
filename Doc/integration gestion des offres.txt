## 5️⃣ Routes

```php
<?php
// routes/web.php

use App\Http\Livewire\Offres\ManageOffres;
use App\Http\Livewire\Offres\OffresList;

// Routes publiques
Route::get('/offres', OffresList::class)->name('offres.index');

// Routes producteur (authentifié)
Route::middleware(['auth', 'role:producteur'])->group(function () {
    Route::get('/mes-offres', ManageOffres::class)->name('offres.manage');
});

// Routes admin
Route::middleware(['auth', 'role:admin'])->group(function () {
    Route::get('/admin/offres', ManageOffres::class)->name('admin.offres.index');
});
```

## 6️⃣ Guide d'Intégration Rapide

### Étape 1: Migrations

```bash
php artisan migrate
```

### Étape 2: Seeder pour les catégories (optionnel)

```php
<?php
// database/seeders/OffreSeeder.php

namespace Database\Seeders;

use Illuminate\Database\Seeder;
use App\Models\Offre;
use App\Models\User;

class OffreSeeder extends Seeder
{
    public function run()
    {
        $producteurs = User::where('role', 'producteur')->get();

        foreach ($producteurs as $producteur) {
            Offre::create([
                'producteur_id' => $producteur->id,
                'titre' => 'Maïs bio de qualité supérieure',
                'description' => 'Maïs cultivé sans pesticides, idéal pour l\'alimentation humaine et animale. Produit frais de notre ferme.',
                'categorie' => 'cereales',
                'prix' => 500,
                'quantite' => 1000,
                'unite' => 'kg',
                'localisation' => 'Douala, Littoral',
                'region' => 'Littoral',
                'ville' => 'Douala',
                'date_publication' => now(),
                'statut' => 'active',
                'contact' => $producteur->phone,
            ]);
        }
    }
}
```

```bash
php artisan db:seed --class=OffreSeeder
```

## 🎨 Personnalisation

### Changer les couleurs

Dans le fichier Blade, modifiez la configuration Tailwind :

```javascript
colors: {
    primary: {
        500: '#votrecouleur',
        600: '#votrecouleurplus foncée',
    }
}
```

Dans le Model `Offre.php` :

```php

{

        'cereales' => 'Céréales & Grains',
        'nouvelle_categorie' => 'Votre Nouvelle Catégorie',

    ];
```
